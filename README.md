# TruthLens

AI-powered fake-news detection project combining a browser extension,
Django web application, and a machine-learning component.

## Project Structure

- `extension/` — browser extension
- `backend/` — Django web application and API
- `ml/` — machine-learning model files and documentation

## Status

The repository is being consolidated from the original project phases.
The ML archive supplied for cleanup is password-protected, so its model
artifacts have not been copied into this package yet.

## Security

Local databases, virtual environments, caches, and environment files are
excluded through `.gitignore`.
